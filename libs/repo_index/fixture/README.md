# repo_index fixture

A tiny tree for the unit tests of `libs/repo_index`. It is committed test data, under PLAN
§11.4: Ivan's decision that the index's tests and eval set go in the repo.

The tests use it two ways:

- **As a `tree` circle.** The tests commit it into a scratch git repository and index it with
  these exclusions:
  - `excluded/`: provenance `IndexOwnData`. The term `fixture_sentinel_excluded` must never
    appear in any chunk, term or statistic, whether from the base or the overlay.
  - `notes/`: claimed by the notes circle (provenance `ClaimedBy`).
- **As a notes circle `notes:topic-a`,** read from disk, the way real notes are: untracked
  directories, never git objects. It has two sources:
  - `notes/topic-a`, label `topic-a`;
  - `notes/local-a`, label `fixture/notes/local-a`, standing for a repo-local `local/` directory.

What each part exercises:

- **`alpha`:**
  - a described crate with a `//!` header;
  - documented and undocumented items;
  - an impl whose methods become items;
  - a trait, a macro and a const;
  - a path dependency on `beta`;
  - `src/tables.rs`, a generated file ("Generated by … do not edit"): skeleton only.
- **`beta`:**
  - a crate with no description and no header;
  - `src/broken.rs`, whose delimiters do not pair: a bag of identifiers.
- **`libs/app_registry/apps.json`:** one app, `spinner`, whose package is `fixture-alpha`.
- **`docs/guide.md`:** Markdown sections, with a fenced block holding a fake heading.
- **`ui/demo.splash`:** splash top-level definitions.
- **`notes/topic-a`:**
  - Markdown sections citing `alpha/src/lib.rs:15` and the item `Gizmo::spin`;
  - `COPY.md`, byte-identical to `PLAN.md`, which must collapse into one hit;
  - `spin.rs`, a non-Markdown note: one `note-file` chunk;
  - `pixel.bin`, binary: a record of its path only.
- **`notes/local-a/spin.rs`:** the same file name as `topic-a/spin.rs` but different content.
  The label prefixes keep their paths and handles apart.
